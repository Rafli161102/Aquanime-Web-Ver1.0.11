# AquaNime website workspace

## Required agent rules
- Read `.agents/skills/antislop/SKILL.md` before any implementation.
- For interface work, also read `antislop-ui`, `antislop-human`, and `antislop-layoutmobile`.
- For public-facing copy, read `antislop-copywriting`.
- For code comment changes, read `antislop-code`.
- Read `DESIGN.md` before changing visual direction.
- Keep corporate and community experiences distinct. Never merge their navigation, content voice, or conversion goals.
- Do not invent company registration data, operational metrics, events, partners, testimonials, member counts, or claims. Use only verified source content; mark unknown contact details as configuration placeholders.
- Keep legacy `frontend/` intact until the new sites are reviewed and migration is approved.
- Before release, run the Anti-Slop Delivery Gate and report PASS/FAIL with evidence.
